    Interface CodingPack

    A national code overlay. translation packs keep the WHO codes and only localize the display (cheap: BNO-10, MKCH-10, and the dental chapter of ICD-10-GM/CIM-10). modification packs remap the code itself (US ICD-10-CM, added in DX-5).
