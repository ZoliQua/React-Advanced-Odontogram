    Type Alias AnatomyProfile

    Everything anatomy-specific, bundled so a runtime switch swaps it atomically. templates/templatesOccl hold inlined SVG text; toothTemplate maps each FDI tooth to its {tpl,rot,mirror}; occlusalTemplate is optional (only a profile that splits front/occlusal artwork populates it — classic reuses toothTemplate); layout drives the buildGrid branch; the three *CejY records are the perio-chart baseline anchors.
